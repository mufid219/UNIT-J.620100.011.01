# UNIT-J.620100.011.02

## Informasi Program

Program ini merupakan contoh sederhana menggunakan Node.js. Saat dijalankan,
program mencetak teks `hello world` ke terminal.

Kode program berada di [`src/index.js`](./src/index.js), sementara perintah
`npm start` didefinisikan di [`package.json`](./package.json).

## Persyaratan

- Node.js dan npm

Program hanya menggunakan modul bawaan Node.js, sehingga tidak perlu
menginstal dependensi tambahan.

## Cara Menjalankan

Dari root repositori, jalankan:

```bash
cd UNIT-J.620100.011.02
npm start
```

Atau, jika terminal sudah berada di direktori `UNIT-J.620100.011.02`, jalankan:

```bash
npm start
```

Program juga dapat dijalankan langsung tanpa npm:

```bash
node src/index.js
```

Semua cara di atas menampilkan keluaran berikut:

```text
hello world
```

# UNIT-J.620100.011.02

Latihan ini adalah program Node.js sederhana yang mencetak `hello world` ke
terminal. Kode program berada di [`src/index.js`](./src/index.js).

## Persyaratan

- Node.js

Program menggunakan modul bawaan Node.js dan tidak memerlukan dependensi
tambahan.

## Menjalankan

Dari folder `hari-14-uji-kom/unit-3`, jalankan:

```bash
npm start
```

Atau jalankan berkasnya secara langsung:

```bash
node src/index.js
```

Kedua cara tersebut menampilkan:

```text
hello world
```
